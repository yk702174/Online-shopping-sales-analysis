# Online Shopping Sales Data Analysis Using Python

## 📌 Project Overview

This project focuses on analyzing online shopping sales data using Python. The project demonstrates data handling, data cleaning, exploratory data analysis (EDA), and data visualization techniques.

The analysis helps identify sales trends, high-performing product categories, top products, revenue-generating cities, customer payment preferences, and other useful business insights.

## 🎯 Objectives

* Analyze online shopping sales data using Python.
* Perform data cleaning and preprocessing.
* Calculate important sales KPIs.
* Identify the best-performing product categories and products.
* Analyze monthly sales trends.
* Compare revenue across different cities.
* Analyze customer payment methods.
* Create meaningful data visualizations.
* Generate useful business insights from the dataset.

## 🛠️ Technologies Used

## 📊 Dataset

The dataset contains **1,000 simulated online shopping transactions**.

The main columns include:

* Order ID
* Order Date
* City
* Gender
* Age
* Category
* Product
* Quantity
* Unit Price
* Discount Percentage
* Total Amount
* Payment Method
* Order Status

> **Note:** The dataset is simulated and created for educational purposes.
